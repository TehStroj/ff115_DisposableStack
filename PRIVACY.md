# Privacy policy

DisposableStack for Firefox 115 does not collect or transmit personal data or
other user data. It makes no network requests and has no analytics, telemetry,
advertising, or remote code.

## Site access

The add-on runs only on `https://chatgpt.com/*` and frames permitted by its
content-script configuration. Firefox may describe this permission as access
to data on `chatgpt.com`. That access is necessary to install the missing
JavaScript APIs in the page's own context before page scripts run.

The add-on does not scan page content, monitor typing, record conversations,
read cookies, or collect browsing history. It has no background process and
does not use extension storage. It keeps only the in-memory resource and
cleanup state needed when a page uses the disposal APIs. That state is not
logged, persisted, or sent anywhere by the add-on.

The website's own network requests and data practices are controlled by the
website, independently of this add-on.

## Support

Privacy questions can be raised at
<https://github.com/TehStroj/ff115_DisposableStack/issues>. GitHub issues are
public, so do not include private conversations, credentials, or other
sensitive information. Information voluntarily submitted there is handled
by GitHub; the add-on does not submit issues or diagnostics automatically.
